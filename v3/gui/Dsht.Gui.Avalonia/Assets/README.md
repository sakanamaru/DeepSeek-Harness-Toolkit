## 来源脉络（依据[萌娘百科「DeepSeek娘」](https://mzh.moegirl.org.cn/DeepSeek%E5%A8%98)条目正文）

本图标画的是社区流行的「**女仆鲸鱼娘**」形象，其脉络（逐条引自该条目「发展历史」小节）：

| 时间 | 作者 | 事件 |
|---|---|---|
| 2025-06 | **上善无形** | 以 AI 创作原创角色 **溟月**，确立蓝色渐变长发、呆毛、鲸类头鳍、蓝瞳、大型鲸尾等特征。**该形象最初是独立原创 OC，与 DeepSeek 无关。** |
| 2026-04-25 | **ZipZipPipe** | 使用 GPT Image 2 在该形象基础上**加入 DeepSeek 元素**并换上深蓝白女仆装，形成如今流行的女仆鲸鱼娘及其衍生形象。 |
| 2026-07-10 | **这个刀子真甜** | 用 Updream 制作 Q 版模型，成为广泛流传的二创形象。 |

此后社区围绕该形象创作了大量（多数为 AI 生成的）表情包与衍生作品。

**本仓库这三个 PNG**：由 **Kimi** 为 dsh-minato 生成，角色设定参考上述条目（女仆鲸鱼娘一支）。
